# 个人菜单 · 02 版

快照日期：2026-08-13
基线：在 01 版基础上，根据产品需求与多轮截图微迭代汇总

## 相对 01 版的主要变更
1. **导航精简为 5 个 tab**：首页 / 菜单 / 计划 / 趋势 / 建档（原「晒饭」的今日运动、手动调整并入「计划」）
2. **首页**
   - 「今日体重」输入框改为胶囊圆角，与保存按钮同款
   - 昵称「小厨师」、副标题「两人食堂 · 今日营业中」均可编辑
   - 问候语「早上好，阿东哥」整行可编辑（失焦/回车保存）
   - hero 改为联网天气模块：定位 + 温度 + 湿度 + 换城市（Open-Meteo / BigDataCloud / geolocation）
   - 天气卡片改浅暖橙风格；右上角头像改为「设置」按钮
3. **菜单页**
   - 4 个餐次卡片改为 2 列网格（早餐+午餐 / 晚餐+加餐）
   - 「偏好」模块从计划页移到菜单页顶部
   - 餐次标题前的 emoji 图标已移除
4. **早餐标签系统**
   - 内置 29 种常吃早餐食物加 `tags:['早餐']` 徽章
   - 手动添加食物表单增加「早餐」开关
   - 非早餐内置食物可在食物列表自由标记/取消早餐标签（持久化）
   - 「生成今日菜单」时早餐仅从带早餐标签食物随机选取
5. **计划页**
   - 顺序：偏好 → 今日运动 → 手动调整
   - 生成结果增加「收起」按钮；采用为今日菜单后自动收起
6. **设置**
   - 新增「主屏图标」上传（同步 PWA manifest / favicon / apple-touch-icon）
7. **添加食物弹窗**
   - 搜索框、手动添加切换、自定义表单整体包入圆角卡片 `.add-food-card`
   - 「展开填写营养成分」增加向下箭头；早餐标签右侧提示「（如果是早餐请点亮早餐按钮）」
   - 头部图标（菜单/计划/趋势/建档）统一为橙色线性 SVG 风格
8. **修复**：首页体重保存写到正确日期；添加食物弹窗系统食物列表渲染异常（数组误当 Set 用）
