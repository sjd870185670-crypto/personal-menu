# 个人菜单 · 01 版

快照日期：2026-08-13
基线：个人菜单静态网页 PRD v1.0 + 情侣菜单风格参考图

## 包含模块（共 7 个，对应 PRD 7.1）
1. 首页 — 今日热量/宏量进度仪表盘
2. 建档 — 个人档案 + BMR/TDEE/目标热量预览（独立页面）
3. 菜单 — 早/午/晚/加餐四餐记录
4. 晒饭 — 运动消耗（MET 计算）
5. 计划 — 一键生成今日菜单（支持素食/低脂/高蛋白偏好）
6. 趋势 — 体重与热量差额折线图（Chart.js）+ 周/月小结
7. 设置 — 数据导出/导入/清空（localStorage）

## 文件
- index.html
- css/style.css
- js/calc.js     热量与宏量计算引擎
- js/fooddb.js   食物库（50 种）+ 活动库（16 项）
- js/store.js    localStorage 持久化
- js/app.js      页面逻辑与渲染
